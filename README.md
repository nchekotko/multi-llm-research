# Signal Lab · Multi-LLM Research

Локальная исследовательская система для фьючерсов MOEX: данные AlgoPack, реестр гипотез, воспроизводимые бэктесты и несколько ролей LLM через один ключ OpenRouter.

## Рабочее пространство

- **Обзор:** покрытие данных, исследования, результат OOS и наблюдения сканера.
- **Данные:** загрузка AlgoPack, неизменяемые снимки, состав инструментов и интервалы покрытия.
- **Исследования:** регистрация параметров, запуск часового сценария, отчёты и replay.
- **Бэктесты:** сценарии комиссий, спреда, impact, доступного объёма и размеров позиции.
- **Сканер:** фильтры по контракту и семейству аномалий, признаки и время доступности.
- **Реестр гипотез:** чтение существующего Economic Calendar без изменения исходных баз.
- **Задачи:** фоновая очередь выгрузок, расчётов и проверок; прогресс сохраняется на диск.
- **Модели:** фактические роли и область квалификации подключённой конфигурации.

Интерфейс входит в FastAPI-приложение. Node.js и отдельная сборка фронтенда для запуска не нужны.

## Быстрый запуск

Python 3.12+, Windows PowerShell:

```powershell
git clone https://github.com/nchekotko/multi-llm-research.git
cd multi-llm-research
.\start.ps1
```

Откройте http://127.0.0.1:8088/ и вставьте **локальный API-токен**, который напечатан в терминале. Это не ключ OpenRouter. Токен хранится в sessionStorage текущей вкладки.

Ручная установка (также Linux/macOS, с соответствующим путём к Python окружения):

```text
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.lock.txt
.venv/Scripts/python -m pip install --no-deps -e .
.venv/Scripts/python -m application serve --port 8088
```

Чистая установка использует демонстрационную конфигурацию моделей; рыночные данные не встроены. Синтетический пример ядра: `python -m application demo`. Он не имитирует реальные результаты MOEX.

## Подключение источников

1. **OpenRouter:** `./connect-openrouter.ps1`; скрытый ввод ключа, проверка моделей и запуск на порту 8089. Откройте корень адреса вместо `/docs`. Проверка вызывает платные API в пределах заданного бюджета. [Настройка моделей](docs/openrouter.md).
2. **Economic Calendar:** скопируйте `config/economic-calendar.example.json` в `config/economic-calendar.json`, задайте путь к своему экземпляру проекта. [Исследовательский профиль](docs/research.md).
3. **AlgoPack:** скопируйте `config/algopack.example.json` в `config/algopack.json`, настройте источник `MOEX_ISS_TOKEN` и при необходимости доверенный CA. Затем используйте экран «Данные». Нужен собственный доступ к продуктам MOEX. [Данные и исполнение](docs/algopack.md).

Локальные ключи, конфигурации, базы, выгрузки и результаты исключены из Git. Публичный репозиторий содержит исходный код, тесты и шаблоны. GitHub не является сервером этого приложения.

## Контроль исследований

Расчёт метрик выполняется кодом. LLM не меняет PnL и программные блокировки. Исследование по умолчанию локальное, без отправки данных моделям. Разрешённые внешние рецензии настраиваются отдельно через политику задачи.

Сигнал сканера — непроверенная гипотеза. Агрегаты AlgoPack не восстанавливают очередь заявок и отдельные «стены». Сценарный impact, комиссии и модель ликвидности не доказывают фактическое исполнение. Требуются независимый OOS, контроль перебора и проверка качества исходных данных.

Сервер рассчитан на одного доверенного локального оператора и один процесс на каталог состояния. Слушает loopback; публичный многопользовательский хостинг потребует отдельной аутентификации и изоляции. Торговых заявок приложение не отправляет.

## Проверка и устройство

```text
python -m pip install -e ".[dev]"
python -m pytest -q
python -m ruff check application tests scripts
node --check application/web/app.js
```

Docker-тест пропускается без подходящего daemon/image. CI проверяет исходники на Linux и Windows. Работа внешних провайдеров и доступ к платным данным проверяются отдельно на локальной конфигурации.
