# Интерфейс Signal Lab

Откройте корневой URL сервера и введите его локальный bearer token. Ключи провайдеров вводятся вне веб-интерфейса. Можно использовать персональную ссылку: её секрет находится во фрагменте URL, обменивается на HttpOnly-сессию на 30 дней и удаляется из адресной строки. «Выйти» удаляет сессию браузера. Настройки показывают активные модели текущего процесса.

Рекомендуемый порядок: проверить каталог данных → создать часовое исследование → загрузить соответствующие контракты AlgoPack → выполнить сценарий исполнения → проверить replay и изучить отказы. Сканер всего рынка использует отдельную выгрузку; его наблюдения требуют последующих зарегистрированных исследований.

Формы создают реальные задачи. Статус обновляется при активных расчётах; также доступна кнопка обновления. JSON можно экспортировать для локальной проверки. Реестр гипотез доступен только для чтения. Новая форма исследования запускает локальный профиль без платных вызовов LLM; внешние рецензии настраиваются через контракт API/CLI.

Очередь аналитики обслуживает одну задачу за раз, хранит прогресс и отмечает прерывание после перезапуска. Не запускайте два сервера на одном каталоге состояния. Долгая задача не блокирует навигацию.
