# Проверка критериев ТЗ

Статус относится к локальному MVP и синтетическим fault-injection тестам. Он не является приёмкой production или квалификацией реальных моделей.

| ID | Реализация и проверка | Статус |
| --- | --- | --- |
| AC-01 | Pydantic extra=forbid, обязательные поля, негативные объекты, schema/semantic gates | Проверено на включённом негативном наборе |
| AC-02 | Checkpoints/receipts, WAL, lease; тесты потери процесса и hard exit через os._exit | Проверено локально |
| AC-03 | Повтор submit с ключом не создаёт новый run; повтор исполнения не создаёт вторые artifacts/model calls; межrun parents запрещены | Проверено для поддержанных локальных эффектов; exactly-once внешнего API не обещается |
| AC-04 | Reservation до запроса, atomically checked budget, остановка новых вызовов, unknown-cost accounting | Проверено синтетически; тарифы/счёт реального провайдера не проверялись |
| AC-05 | План не расширяет tools/roles/gates; no-external политика проверяется кодом | Проверено негативными тестами |
| AC-06 | Docker runner и интеграционный тест host/secrets/network/timeout поставлены | Не подтверждено: Docker daemon недоступен; тест пропущен |
| AC-07 | Task/config/code/schema/prompt hashes, зависимости, receipts, usage, latency, artifacts, timeline, approvals; export и replay | Проверено на полном офлайн-прогоне |
| AC-08 | Изолированный reviewer, сохранение blockers, resolutions на свежую validation и изменённый candidate; запрет ручного override rejected run | Проверено синтетическими известными дефектами |
| AC-09 | Дословные факты и программные расчёты, reporter не пишет числа; numeric_lineage проверяется replay | Проверено в evidence_report; истинность исходников остаётся ограничением |
| AC-10 | Реальные адаптеры проверены MockTransport; fallback применяет квалификацию/data policy/контракт/tier | Контрактные проверки пройдены; предметный eval альтернативных реальных моделей ещё нужен |
| AC-11 | Три eval-конфигурации, затраты workflow, известные дефекты и контрольные примеры | Не подтверждено: синтетика не доказывает экономию/качество реальных моделей |
| AC-12 | Quant research явно не активирован | Не применяется к поставленному профилю |

В поставке есть исходники, роли/config, JSON Schema, lock-файл, локальный запуск, миграции, тесты, synthetic eval и сравнение, модель угроз, runbook и пример полного запуска с lineage/accounting. Архитектурный MVP готов к локальной проверке; эксплуатационная приёмка требует выбранного предметного процесса, реального eval, проверки Docker и согласованных SLO.
