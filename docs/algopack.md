# AlgoPack: данные, исполнение, сканер

Скопируйте `config/algopack.example.json` в `config/algopack.json`. Ключ берётся из переменной окружения `credential_name` либо одноимённой строки файла `credential_file`. Сам ключ в JSON не записывается. `ca_bundle` может указывать на дополнительный доверенный PEM; проверка TLS всегда включена.

На экране «Данные» выберите контракты и период либо выгрузку всего срочного рынка. Правая граница исключена. Для контрактов допустимо до 180 дней, для всего FO до 31 дня. TradeStats, OBStats и OrderStats — агрегаты; минутные свечи доступны в контрактной выгрузке.

Страницы сохраняются с параметрами, временем получения и хешами. Пагинация продолжается до пустой страницы; дубликаты, чужие даты и некорректные ответы отклоняются. Незавершённая выгрузка не имеет финального манифеста. Повтор использует кэш. Данные и результаты находятся в `var/algopack`, не в Git.

В «Бэктестах» выберите снимок и завершённое исследование из текущего каталога состояния. Модель учитывает доступность OBStats/TradeStats, предел возраста, половину спреда каждой ноги, сценарный impact, комиссию и ограничения доли глубины/потока. Обе ноги должны пройти фильтры. Неисполненный выход сохраняет открытую позицию и её риск. ГО — ограниченная оценка, не полный счёт ВМ. Сравниваются train/OOS, размеры позиции и множители издержек.

Сканер проверяет пять семейств:

- дисбаланс стакана совместно с направлением сделок;
- поглощение направленного потока;
- аномалии отмен/выставлений при своевременном OrderStats;
- провал ликвидности и расширение спреда;
- объём совместно с изменением открытого интереса.

Нормировка использует предыдущие дни и доступные на тот момент интервалы. `SYSTIME` может отложить доступность; недоступный OrderStats отключает соответствующий детектор. Score не является p-value, а кандидат не является доказанной неэффективностью. Для отдельной заявки-стены или spoofing нужны подробные события стакана.

Длительные операции UI отправляет в `/v1/console/jobs`: очередь сохраняется, интерфейс показывает состояние и прогресс. Старые синхронные API сохранены. Завершённые снимки неизменяемы, кнопки replay проверяют воспроизводимость без новой загрузки. После рестарта прерванную задачу следует отправить повторно; кэш страниц сохраняется.

CLI: `algopack-download`, `liquidity-backtest`, `liquidity-replay`, `market-scan`, `market-scan-replay`. Примеры JSON содержат демонстрационные идентификаторы: замените их на ID собственной выгрузки/исследования. Не публикуйте лицензированные данные и локальные результаты вместе с кодом.
